# Section example images

Each of the eleven sections has its own Pinterest reference photograph. Every image-generation request supplied the actual reference image file as an input. Options within the section retain that reference scene while changing the selected setting. The local interface displays one selected variation per section; each caption links to its original Pinterest pin. Example images are AI variations, not a live preview of the user's subject. Lens and viewpoint images are illustrative; they are not measured optical simulations.

The examples cover Language (6), Lens (7), Viewpoint (7), Depth & focus (4), Composition (4), Lighting (6), Atmosphere (4), Color relationship (6), Surface direction (6), Image finish (4), and Detail (3). Saved choices, notes, draft prompts, color roles and import/export continue to use the existing schema.

The full prompt set, reference source and input/output hashes are in `example-provenance.json`. The raster atlases live in `dist/assets/examples/`. No Claude calls were used for this update. The earlier procedural arch and from-scratch drafts are excluded from these selected assets.
